# 端侧 AI Studio · 视觉创作工作台

**在本机画布上组织素材、图像与视频任务，批量导出创作结果。**

面向视觉内容创作的本机工作台原型，围绕画布、任务队列与批量导出验证完整产品流程。

## 创作流程

上传素材 → 选择风格与任务 → 队列执行 → 结果进入画布 → 图层组合 → 按平台尺寸批量导出。

## 核心能力

- 项目与素材管理、画布图层、风格模板和导出规格。
- 图像、视频、导出三条任务泳道。
- 暂停、继续、取消、重跑与优先级调整。
- 任务持久化、崩溃恢复和生成产物回滚。
- 权限边界、审计记录与本机数据保存。

技术栈：Python · FastAPI · 原生 JavaScript · 本地任务与文件存储。

## 当前阶段

第一版可运行骨架，已打通任务、画布、批量导出及恢复流程。当前图像和视频由本地 **Mock 后端**生成占位内容，真实模型生成效果尚未完成集成验收；预留本地模型 HTTP 适配接口。
